# 어휘 교정 가드 — 설계

2026-08-08 · 근거: 어휘 감사(코퍼스 34편, 발굴 72→3인 교차판정 확정 29건) · 사용자 승인 범위: A+B+C+D 전부

## 원인 → 방어 대응

| 원인(실측) | 방어 |
|---|---|
| 동음이의·전문 한자어(방조·시비·동해·가식·해토·부후·결각·가부) | A 지침 + B 브랜드 목록 + D 린트 |
| 요약·마무리 비문('-고' 접합 붕괴, 주술 불일치) | A 지침 ⑤ |
| SEO 키워드 통삽입("묘목선별하면") — 정확 표기 강제와의 충돌 | A: 강제 지침에 "자연 결합" 단서 |
| 조어 파생 전파("쉬움"→쇼츠) | A 지침 ③(4경로 공용이라 파생도 받음) |
| TTS 숫자 한글화가 "십월" 생성 | C 결정적 치환 |

## A. 어휘 가드 지침 — `LEXICON_GUIDE` (org.ts 공용 상수 패턴)

`lexiconGuide(avoid?)` 함수(브랜드 목록 주입형)로 만들어 4경로에 주입:
1. 블로그 작가(`writeBlogBody` context) 2. 카드 기획자(`planCards`) 3. 쇼츠 작가(`planShorts`) 4. 제목·메타 패키저(`packageNaverBlog`).
내용: ①모르는 압축 한자어 풀어 쓰기 ②다른 뜻으로 먼저 읽히는 말 금지 ③사전에 없는 조어·억지 명사화 금지 ④키워드는 명사구로 자연 결합(동사화 금지) ⑤요약·마무리에서 무관한 두 내용 '-고' 접합 금지 + (브랜드 목록 있으면) "다음 말은 반드시 이렇게 풀어 쓴다: 방조→…".
키워드 정확 표기 강제 문구(planCards·planShorts·PACK_SYSTEM)에 "표기는 그대로 포함하되 문장과는 조사·별도 문장으로 자연스럽게 결합(키워드에 어미를 붙여 동사화 금지)" 단서 추가.

## B. 브랜드 설정 `avoidJargon`

`BrandProfile.avoidJargon?: Array<{ term: string; use: string }>` — 업종어라 yaml에(브랜드 격리). bionditree 시드(확정 실측분): 방조→새 그물 씌우기 · 시비→비료 주기 · 동해→겨울 추위 피해 · 가식→임시로 묻어 두기 · 해토→땅이 풀린 뒤 · 부후→썩어 들어감 · 결각→잎 가장자리 갈라짐 · 가부→해도 되는지. 미설정 브랜드는 일반 지침만(종전 동작).

## C. 결정적 월 이름 치환 (쇼츠)

`cleanNarration`(shorts.ts)에서 십월→시월·육월→유월 치환(항상 잘못이므로 프롬프트에 안 맡김). 낭독·자막 동시 교정. 기획 프롬프트 숫자 한글화 지시에 예시 보강("10월→시월, 6월→유월").

## D. 어휘 린트 2차 방어

순수 `lintLexicon(text, avoid)` → 걸린 용어 목록. 초안 SEO 게이트의 리비전 피드백(`seoReviseFeedback`)에 어휘 교정 항목 동봉 — **새 리비전 트리거는 만들지 않음**(비용 불변, SEO 리비전이 돌 때만 함께 교정). 미발동 시 로그 한 줄로 가시화.

## 범위 밖

기발행물 소급 수정(수동 판단) · 형태소 분석 기반 비문 검출(프롬프트 예방만) · 29건 개별 문서 수정.

## 검증

유닛(lintLexicon·치환·지침 조립) + 실코퍼스 스모크(확정 29건 중 avoidJargon 대상이 실제로 걸리는지) + 다음 1~2편 실물 관찰(가드 로그).
