# 24절기 시의성 신호 주입 — 설계

2026-08-07 · 사용자 제안("24절기도 좋은 글감") · 용도 확정: 시의성 신호 주입만(도입 훅 강제·절기 SEO 타겟·시리즈 기획은 선택 안 함)

## 문제

자율 아이디어·리서치 두뇌의 프롬프트는 "시의성·계절성을 고려하라"고 지시하지만 **오늘 날짜를 알려주지 않는다** — 시간을 안 주고 시의성을 요구하는 공백. 절기는 이 공백을 메우는 가장 자연스러운 달력 신호다(나무 작업은 절기 단위로 움직인다).

## 설계 (승인안 A)

- **새 파일 `src/util/solarTerms.ts`** (순수):
  - 24절기 고정 날짜 표(이름·월·일·한 줄 의미). 실제 절기는 해마다 ±1일 변동하나 시의성 신호 용도로 하루 오차는 무의미 — 연도별 천문 표는 YAGNI 기각.
  - `seasonalContext(now: Date): string` → `"[오늘] 8월 7일 — 절기: 입추(가을의 시작), 다음 절기: 처서(8/23, 더위 꺾임)"`. 절기 경과 시 `+N일` 표기, 연초·연말 랩어라운드 처리.
- **주입 2곳** (`src/autonomy/scheduler.ts`): `proposeContentIdeas`·`proposeResearchMission` 프롬프트 앞부분에 한 줄. 나무 작업 함의는 하드코딩하지 않는다 — LLM 이 절기 의미와 브랜드 컨텍스트를 결합해 스스로 끌어낸다(업종 의미를 코드에 넣지 않는 브랜드 격리 원칙).
- 킬스위치 불필요(순수 컨텍스트 한 줄 — 문제 시 주입 줄 제거).

## 범위 밖

작가 도입 훅 강제 · 절기 합성 키워드 SEO 타겟(수요 실측 선행 필요) · 24편 시리즈 예고 등록.

## 검증

절기 경계 유닛(당일·전날·경과일·연초/연말 랩어라운드) + 주입 후 자율 틱 로그 관찰(실런).
